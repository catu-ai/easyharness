# Release v0.6.0-rc.4

## Goal

Publish `v0.6.0-rc.4` as the release follow-up for the review-round ancestry
deadlock and supported abort recovery landed in PR #297. Keep the release
candidate narrow and use the existing VERSION-driven tag, archive, and
Homebrew automation.

### Decisions and Constraints

- Advance from `0.6.0-rc.3` to `0.6.0-rc.4`; do not promote the RC line to
  stable `0.6.0` in this slice.
- Keep the release candidate to the dedicated VERSION bump unless validation
  reveals a release-blocking correction that requires explicit scope review.
- Require the full release validation profile and the ordinary independent
  finalize review before publishing the release PR.
- After explicit release-PR merge approval, treat tag creation, GitHub release
  assets, Homebrew tap update, upgrade, and `brew test` verification as required
  land bookkeeping before returning to idle.

## Scope

### In Scope

- Set the repository release version to `0.6.0-rc.4`.
- Validate the release candidate through the tracked release workflow.
- Publish the dedicated release PR and, after separate merge approval, verify
  the automated prerelease and Homebrew delivery.

### Out of Scope

- Product, workflow, documentation, or schema changes unrelated to the release
  version.
- Stable `v0.6.0` release selection or closure of the v0.6.0 umbrella issue.
- Manual tag creation or bypassing VERSION-driven release automation.

## Acceptance Criteria

- [x] `VERSION` is exactly `0.6.0-rc.4`, and the candidate contains no unrelated
      product changes.
- [x] The complete release validation profile passes for the RC4 candidate,
      including packaging, installer, release, and Homebrew formula smoke
      coverage.

## Review Focus

- Confirm `0.6.0-rc.4` is the correct monotonic prerelease successor to the
  currently published `v0.6.0-rc.3`.
- Verify the release diff stays narrow and does not accidentally select stable
  `v0.6.0` or alter release automation.
- Check that existing VERSION-driven workflows will publish a prerelease and
  update the default Homebrew formula after merge.
