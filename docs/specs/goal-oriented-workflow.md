# Goal-Oriented Workflow

## Status

Goal-oriented workflow is deferred to `v0.7.0`. It is not part of the current
normative harness contract.

The current CLI does not expose goal-oriented plan authoring, recognize
`workflow_profile: goal_oriented`, or define checkpoint, scorecard, probe,
challenge, synthesis, archive, reopen, status, or UI behavior for that profile.
Use the standard compact plan workflow for current work.

This file is a non-normative roadmap pointer. It must not be used to infer
commands, plan fields, state transitions, validation rules, or lifecycle
behavior.

## Deferred Direction

The `v0.7.0` design may revisit objective-driven investigation where the
outcome is explicit but the execution path must adapt through evidence. That
work should define the profile end to end before exposing it, including plan
authoring, lint, execution, progress, review integration, archive and reopen,
status guidance, and UI behavior.

Until that work is approved and implemented, goal-oriented concepts remain
deferred rather than partially supported.
